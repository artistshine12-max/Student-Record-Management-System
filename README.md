# Student Record Management System

Mini Project, OOP using C++

**Built by Shine and Atul Gangwar**

A console-based Student Record Management System developed in **C++** using **Object-Oriented Programming (OOP)** concepts. The application allows users to manage student records efficiently through a menu-driven interface.

The system provides features for adding, viewing, searching, updating, and deleting student information while demonstrating core OOP principles such as classes, encapsulation, and data management.

## Features

- Add new student records
- Display all student records
- Search students by Roll Number
- Update student details
- Delete student records
- Prevent duplicate roll numbers
- Menu-driven user interface
- Easy record management

## Student Information Stored

Each student record contains:

- Roll Number
- Name
- Age
- Course/Class
- Marks
- Grade (if applicable)

## Classes

### Student
Stores student details and provides functions to access and update information.

### StudentManagementSystem
Manages all student records and handles operations such as add, search, update, delete, and display.
